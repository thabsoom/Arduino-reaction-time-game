# Arduino-reaction-time-game
## Overview
This project is a two-player reaction time game built using Arduino, where players respond to LED cues as quickly as possible. The system evaluates responses and updates scores in real time.

## Features
- Two-player gameplay
- LED-based visual cues
- Score tracking system
- Real-time feedback
- Winner display at the end

## Components Used
- Arduino
- LEDs
- Push buttons
- Display module
- Resistors and jumper wires

## What I Learned
- Managing real-time inputs and outputs in embedded systems
- Optimizing pin usage on Arduino
- Synchronizing display, sound, and gameplay logic
- Debugging hardware-software interaction
